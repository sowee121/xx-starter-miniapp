一、项目概述
小程序名称（页内展示）：嘻嘻启蒙乐园
微信后台创建 / 搜索名：嘻宝星屋（过审对外名，见 `docs/apply/miniprogram-intro.md`）
适用人群：幼儿园宝宝
产品定位：面向幼儿园宝宝的微信原生轻量化启蒙小程序，严格遵循微信小程序750rpx开发规范、移动端适配标准，对标幼儿园入门内容。整体采用晨间草地柔和治愈风 + 圆角积木控件 + 全系黏土萌系素材/动物独家视觉体系，全程极简交互、护眼低饱和配色、超大操作区域、全正向激励，无任何负面反馈。
核心原则：原生适配、移动端优先、护眼低饱和、极简操作、低难度启蒙、全正向激励、零负面反馈、高清黏土质感、云端数据永久存储
二、全局专属UI视觉风格规范（全站强制统一·终审定稿）
整体视觉唯一定调：晨间草地柔光场景 + 圆角积木立体控件 + 全黏土软萌质感素材/动物
整体氛围：全天护眼柔和治愈风，无刺眼高光、无强烈对比、无花哨动效，画面干净童真、松弛舒适，适配幼儿长时间观看。
1. 场景底色与全局氛围
- 页面背景：全站统一晨间浅绿草地渐变底色，淡嫩绿融合柔光白，模拟清晨自然光草坪效果，通透护眼
- 氛围点缀：仅使用静态浅云、柔光光斑、细腻草地纹理，无任何动态闪烁、无跳动动画、无特效干扰
- 光影规则：全局柔和漫反射光影，无硬阴影、无切割感、无厚重暗角，整体画面轻盈软糯
2. 控件体系：全站统一圆角积木风格
- 所有按钮、功能卡片、选项框、输入模块、弹窗容器均为超大圆角积木造型
- 积木质感：微立体凸起、柔边浅阴影、块面干净，马卡龙低饱和纯色块，无描边、无尖锐角、无复杂纹理
- 可点击区域统一超大尺寸，完全适配幼儿粗手指点击，杜绝误触、点不中、漏触问题
- 页面结构全部采用积木卡片模块化平铺布局，层次清晰、排版规整、留白充足
3. 素材体系：全站唯一黏土质感标准
- 全站所有配图、装饰、认知素材100%统一高清黏土捏塑风格，包含果蔬、物品、自然景物、动物角色
- 黏土标准：肌理柔软、边缘圆润、蓬松立体、低饱和软糯配色，禁止手绘风、扁平风、写实照片、二次元卡通
- 动物素材库（全覆盖）：核心常驻角色：猫、狗、小鸭、兔子、小熊；扩展认知动物：鸡、羊、牛、猪、小鸟、小鱼、狐狸、熊猫、大象、长颈鹿、狮子、老虎、猴子、企鹅、海豚。所有动物表情温和治愈，无凶狠、夸张、惊悚造型，全程作为陪伴、点缀、激励元素使用。
4. 全局固定护眼色彩体系（不可修改）
- 主色调：晨间嫩草绿（低饱和、柔和不刺眼）
- 辅助色：奶油白、浅奶黄、蜜桃浅粉、天空浅蓝（全部低饱和马卡龙色系）
- 禁用色：纯黑、纯白、正红、亮黄、高对比强光色，全站画面统一柔化降饱和，严格保护幼儿视力
三、小程序全局硬性开发规范（终审优化·无漏洞）
1. 尺寸与移动端适配规范
- 设计基准：严格按照微信小程序 750rpx 标准设计稿开发
- 全屏移动端优先布局，彻底无左侧侧边栏，所有功能统一首页平铺卡片入口
- 全页面兼容异形屏、刘海屏、底部手势安全区，所有有效操作区域完全避位系统UI
- 可点击组件最小尺寸：152rpx×152rpx（紧凑点读可用 128rpx），无细小按钮、无密集点击区
- 统一圆角参数：按钮 / pill / chip 24–40rpx、卡片 36–48rpx；取范围内值即可，同级控件全站一致，不强制全站同一数字
- 模块间距统一 30rpx，留白宽松，页面干净不拥挤
- 正文字号最小 28rpx；设计变量见 tokens
2. 全局顶部组件 & 首页专属布局（最终版）
- 关闭小程序原生默认头部，全站使用自定义顶部导航栏，固定高度88rpx，晨间草地柔光底色、积木圆角样式；左侧固定返回主页按钮、中间页面标题、右侧实时星星积分展示。
- 首页独有欢迎模块（内页不显示）：自定义导航下方固定展示黏土可爱头像 + 两行欢迎语「宝贝，你好呀～」「一起快乐学习吧」，整体为圆角积木卡片样式；点击可进入家长区。
- 首页核心布局：八大功能板块全部采用全屏平铺大积木卡片，整齐排列、视觉均衡，适配幼儿园宝宝单手浏览与点击。
- 全局禁止广告、付费、授权弹窗、强制跳转；学习反馈用页内弹层/行内提示，不使用系统 Toast。
3. 字体、交互、语音统一规范
- 字体：全站圆润加粗字体，字号偏大、清晰醒目，无细字体、无花体、无小字密集排版
- 文案：单页极简、无长句、无复杂术语、无大段文字，完全适配幼儿园宝宝认知
- 交互方式：仅支持选择题、拖拽题，禁止手写、输入、键盘弹出、拼写作答
- 答题机制：答错无扣分、无红字、无刺耳提示、无负面话术，全程温柔正向鼓励
- 语音播报：全站统一慢速标准童声，清晰软糯，所有文字、图片、单词、诗句支持单点独立点读发声；拼音单韵母按拼音教法发音（勿念成英文字母）
4. 数据存储规范（最终技术标准）
- 用户积分、每日打卡记录、学习进度、贴纸资产，全部通过微信云函数云端存储，实时云端同步、永久留存
- 更换设备、重启小程序、清空本地缓存，数据不丢失、不重置（家长区主动「清除」除外）
- 不以纯本地缓存作为唯一数据源；加星失败允许本地兜底并云通畅后同步
四、八大启蒙功能板块详细需求（全站UI统一·逻辑闭环）
1. 古诗启蒙板块
精选入门古诗：《咏鹅》《静夜思》《悯农》《春晓》《登鹳雀楼》《望庐山瀑布》
页面采用晨间草地背景，诗句内容放置浅色圆角积木大字卡片，支持逐句单点朗读、全文一键朗读；全文与字母歌等长音频播放中再点同一按钮即可停止，停止后按钮恢复播放态。所有诗意配图为专属黏土质感实景插画，搭配萌系黏土小动物点缀。页面以原文大字区为主，不做白话译文区。
2. 识字启蒙板块
字库按生活热门类型分八类（数字、颜色、动物、家人、身体、自然、方位、出行），每类 12 字共 96 字；分类按好认先学排列，类内按关联性与常见连读顺序排列。数字含一～十与百、千。无「古诗里的字」分库。列表为上 emoji 下汉字的积木字卡；详情用系统 emoji 表意。点击汉字发声，并搭配 1-2 个极简口语组词。首页直达分类列表。
3. 算术启蒙板块
数物对应认知（1-10，10题）：从水果黏土原子池随机选一种，按答案数量拼接展示；布局用固定列数网格（10个为上下各5个），单图随数量自适应缩小。仅选择题。
极简加减运算（结果落在 1～10，10题）：固定使用狗拿算盘黏土图；超大积木圆角选择按键，答对正向激励，无任何负面反馈。
4. 英语启蒙板块
零基础入门：先进枢纽再选字母表或单词。字母表为 26 个大写字母点读（黏土字母图 + 字母名音标，无例句）及列表底部字母歌大按钮（播放中可停止）；单词为日常基础实物词及超短口语短句。所有配图为软萌黏土造型，积木卡片布局，字母名、单词、短句独立单点发声，支持反复跟读。字母名或单词点读播完发星（同页进一次只 1 星，云函数 reason：letter_done / word_done）；字母歌不计星、不计每日任务。
5. 拼音启蒙板块
仅做单韵母零基础入门认知（a o e i u ü），无声母、无复杂拼读、无超纲内容。详情使用纯黏土字母图（非动物拿字卡），支持点读发声，页面极简干净。点读音频按拼音韵母发音：合成时用注音「ㄚㄛㄜㄧㄨㄩ」，禁止把拉丁字母直接丢给中文 TTS（易念成英文字母）。
6. 日历认知板块
晨间草地昼夜主题场景，使用黏土太阳、云朵、月亮、小动物装饰，极简展示日期、星期、昼夜区分；「打卡」按钮放在日期卡内，每天可打卡一次（进入页面不自动完成）；卡下方展示本月学习热力，培养幼儿基础时间认知，无复杂历法知识。
7. 每日任务打卡板块
积木卡片式任务展示：六模块各一条，自由学习按数量累计（不限定当天指定诗/字/字母或单词）。英语任务名统一「学 N 个英语」，点进枢纽，字母名点读与单词点读都计入，字母歌不计。数量每天随机——古诗 1～2，汉字/算术/英语各 1～5，拼音 1～6，日历固定 1（任务名「日历打卡」）；完成即可点亮状态（不可手动点勾），星星按数量发放（古诗为数量+1）。搭配黏土萌系动物点缀，帮助幼儿养成规律学习习惯，打卡记录云端永久存储。
8. 积分奖励商城板块
唯一奖励体系：星星积分兑换黏土风格虚拟贴纸（动物、果蔬、草地童趣系列）。兑换仅点「兑换」按钮；已拥有/星星不足不可点。无勋章、无成就、无复杂体系，纯正向趣味激励，贴纸资产云端保存。
（附）家长区：从首页欢迎卡进入，非八大学习入口。提供点读/答题音量调节；可长按 3 秒清除学习记录、星星积分或已兑换贴纸（破坏性，文案统一「清除」）。
五、积分激励全局规则（唯一闭环逻辑）
幼儿完成任意板块学习、答题、每日打卡，实时获得星星积分，顶部导航栏实时刷新数据。学习流程内积分只增不减、不扣除，仅用于兑换虚拟贴纸；点读详情（古诗全文 / 识字 / 单词 / 字母名 / 拼音）同一次进页只加 1 星，算术每答对一题 +1。任务首次完成另发任务奖励，与单次学习发星相互独立。家长区可主动清除，幼儿答题无负面惩罚。反馈用弹层或行内 soft-note + 音效，禁止 Toast。
